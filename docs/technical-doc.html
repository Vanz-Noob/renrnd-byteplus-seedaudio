2.1. Paralel Pipeline

AI streaming dan TTS berjalan secara paralel menggunakan asyncio.Queue:

  1. AI Producer: Konsumsi SSE tokens dari ModelArk, kirim ke browser untuk display, pecah menjadi kalimat, push ke text_queue
  2. TTS Consumer: Konsumsi kalimat dari text_queue via async generator, kirim ke TTS sebagai TaskRequest, yield audio chunks ke browser

Keduanya berjalan dalam asyncio.gather() sehingga audio kalimat pertama mulai diputar saat AI masih generate kalimat berikutnya.

3. Binary Protocol

3.1. Frame Format

Byte 0: (protocol_version << 4) | header_size
Byte 1: (message_type << 4) | message_type_specific_flags
Byte 2: (serialization << 4) | compression
Byte 3: reserved (0x00)
[4-7]: Optional fields (event, session_id, etc.)
[...]: Payload size (4 bytes) + Payload

3.2. STT Flags

0b0010bit1Last audio packet

4. TTS Session Reuse

Sesuai best practice dokumentasi BytePlus TTS 2.0:

"推荐将流式输出的文本直接输入该接口，而不要额外增加切句或者攒句的逻辑"
Masukkan teks streaming langsung ke TTS, jangan pecah kalimat sendiri.

Implementasi: satu WebSocket connection + satu session untuk seluruh AI response. Multiple TaskRequest dikirim paralel dengan penerimaan audio.

StartConnection → ConnectionStarted StartSession → SessionStarted TaskRequest("Halo!") → audio chunks... TaskRequest("Ada yang bisa...") → audio chunks... FinishSession → SessionFinished FinishConnection

5. Audio Playback (Frontend)

5.1. Format: PCM

TTS output: PCM 16-bit signed, mono, 24kHz. Dipilih karena:

  • Tidak ada framing overhead (vs MP3 yang butuh frame alignment)
  • Bisa di-append tanpa batas
  • Latency minimal (no codec decode)

5.2. Web Audio API - Gapless Playback

// PCM Int16 → Float32
const audioBuffer = playbackCtx.createBuffer(1, sampleCount, ttsSampleRate);
const channelData = audioBuffer.getChannelData(0);
for (let i = 0; i < sampleCount; i++) {
    channelData[i] = dataView.getInt16(i * 2, true) / 32768.0;
}

// Schedule dengan precise timing (zero gap)
sourceNode.start(nextPlayTime);
nextPlayTime += audioBuffer.duration;

5.3. Fallback: WAV Blob

Jika AudioContext dengan 24kHz tidak didukung, PCM dibungkus dengan WAV header (44 bytes) dan diputar via <audio> element.
